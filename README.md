# Team Task Manager

## Features
- Authentication (JWT)
- Role-based access (Admin/Member)
- Project management
- Task management
- Dashboard stats

## Setup
1. npm install
2. Create .env file
3. npm start

## API Routes
- /api/auth
- /api/projects
- /api/tasks
- /api/dashboard
